# AzCCTV — Brand Kit

حزمة تطوير وتسويق مشتقة من 6 ملفات SVG أصلية. **لم يتم تعديل الأصول الأصلية أو حذف أي منها.**

## المحتويات
- `00-originals`: ملفات SVG كما وردت من المستخدم حرفيًا.
- `01-logos`: نسخ SVG الأصلية مسماة، وصور PNG شفافة بعد قص الفراغات حول الرسم.
- `02-web`: ملفات favicon ونسخ PNG متعددة.
- `03-pwa`: أيقونات any شفافة وmaskable بخلفية كحلية وهوامش أمان.
- `04-android`: أيقونات launcher، وطبقات adaptive مبدئية، وأيقونة متجر.
- `05-apple`: Apple Touch وأيقونة مربعة 1024.
- `06-desktop`: Windows ICO/PNG وmacOS ICNS وLinux PNG/SVG.
- `07-marketing`: قوالب صور تحمل الشعار الفعلي بمقاسات جاهزة لتطوير المحتوى.
- `08-print`: PDF متجهي مشتق مباشرة من SVG.
- `09-developer`: ألوان CSS/JSON ومثال HTML وmanifest.

## تنبيهات ضرورية
- الصور التسويقية **قوالب عامة** وليست تصاميم معتمدة لأبعاد أو مناطق أمان كل منصة اجتماعية.
- الملفات لا تتضمن نسخة لغة عربية جديدة للشعار؛ لم نضف نصوصًا غير موجودة بالمصدر.
- طبقات Android adaptive بداية مناسبة للتطوير؛ راجع المعاينة وملفات الموارد الخاصة بإطار العمل قبل النشر.
- `site.webmanifest` مساراته مثال يفترض نقل الملفات إلى `/brand/pwa/`. عدّلها حسب بناء المشروع.
- أيقونات متاجر التطبيقات تحتاج فحصًا نهائيًا لسياسة المتجر/إطار العمل، خصوصًا خلفية iOS.
- أيقونات `maskable` تستخدم الهوامش الآمنة المقترحة، وتحتاج اختبار عرض فعلي قبل النشر.
- نماذج التسويق عبارة عن إطار تصميم ونقطة بداية، وليست بديلًا عن تصميم حملة تتضمن رسالة وصور منتجات.
